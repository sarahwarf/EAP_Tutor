# Default Pedagogy

Files in this folder ship with the repo — unlike materials uploaded via Telegram
(tagged `pedagogy`), which are stored in the local database and are **not**
included when someone forks this project.

Nova uses this folder to ground how she interprets `/note` instructions: what
counts as a mistake to correct versus something to model through repeated
exposure.

**If you fork this project:**
- Keep `example.txt` as-is if you want a starting default.
- Replace it with your own teaching notes, rubrics, or research summaries.
- Delete it entirely if you'd rather rely only on materials uploaded via Telegram.

Only `.txt` files in this folder are read. Any file starting with `[Paste` is
treated as an unfilled placeholder and skipped.
